# 🌸 Mizuki Music

> **A Premium Music Experience for Discord**

Mizuki is a high-performance, minimalist Discord music bot built with `discord.js v14` and `Shoukaku`. It focuses on a clean, professional aesthetic using the latest Discord V2 component system.

---

## ✨ Features

- 🎵 **High-Quality Audio**: Powered by Lavalink with support for YouTube, Spotify, SoundCloud, and more.
- 📺 **Live Progress Tracking**: Player cards update in real-time every 8 seconds to show accurate playback time.
- 🎨 **Minimalist UI**: Modern, clutter-free interface using Sections, Containers, and Thumbnail accessories.
- 🚀 **Advanced Functions**: 24/7 Mode, Autoplay, Volume Control (up to 150%), and premium audio filters.
- 🔌 **Lavalink Logic**: Built-in node management for stable and resilient connections.
- 💎 **Premium System**: Integrated license key and tier system for exclusive features.

## 🛠️ Installation

### Prerequisites
- [Node.js](https://nodejs.org/) v18 or higher
- [MongoDB](https://www.mongodb.com/) Database
- [Lavalink](https://github.com/lavalink-devs/Lavalink) Server (v4 recommended)

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/titanxdevz/Mizuki-Music.git
   cd Mizuki-Music
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment**
   - Copy `.env.example` to `.env`
   - Fill in your Discord Bot Token, Mongo URI, and Lavalink credentials.

4. **Start the bot**
   ```bash
   node .
   ```

## 🎮 Command Preview

| Command | Description |
| :--- | :--- |
| `/play` | Play a song or playlist from any source |
| `/skip` | Skip the currently playing track |
| `/pause` | Pause/Resume the playback |
| `/queue` | View the current song queue with page navigation |
| `/filters` | Apply professional audio filters (Bassboost, Nightcore, etc.) |
| `/stop` | Fully stop the music and disconnect the bot |
